\noindent{\LARGE\bfseries Appendix\par}
\vspace{0.25in}
\label{chap:appendix-source}

The following pages contains C source code listings for four files:\footnote{These
files, together with source code files for the other programs in this book, are
available on diskette; see note in Preface.}
\begin{description}
\item[\textit{smpl.c} ---] the \textbf{smpl} simulation subsystem except for random variate generation functions,
\item[\textit{rand.c} ---] random variate generation functions,
\item[\textit{smpl.h} ---] \textbf{smpl} external name declarations and various user-level directives (for inclusion in simulation programs), and
\item[\textit{stat.c} ---] normal and $t$ distribution quantile computation functions \texttt{Z()} and \texttt{T()} (used by the batch means analysis module of Section 4.7).
\end{description}

An executable instance of a \textbf{smpl} simulation model is formed by
\begin{enumerate}
\item compiling \textit{smpl.c} and \textit{rand.c} (and, if desired, creating a library module from their object modules),
\item compiling the simulation program, which contains \texttt{main()} (and which \texttt{\#includes} \textit{smpl.h}), and
\item linking the simulation program's object module to the \textit{smpl} and \textit{rand} object modules (or their library module) to form an executable file.
\end{enumerate}
Note that there are two versions of \texttt{ranf()} in \textit{rand.c}; the version compiled is determined by the value \texttt{\#defined} for \texttt{CPU} (8086 or 68000). You may want to compile the batch means analysis module of Section 4.7 (which \texttt{\#includes} \textit{stat.c}) and add its object module to your library.
